# Gym Age Classification Program

## Description
This project is a simple Python program that classifies gym members according to their age.  
It is a beginner-level program created to practice conditional statements and user input in Python.

The program asks the user to enter their age and then displays the type of gym class they belong to.

## How it works
1. The program displays a welcome message for the gym system.
2. The user enters their age using the keyboard.
3. The program reads the age and converts it into an integer value.
4. The program evaluates the age using conditional statements (`if`, `elif`, `else`).
5. The system determines the correct class category based on the age.
6. The program prints the result on the screen.

## Status
> The project is currently running as a basic console program and it is demonstrating how age classification works in a gym registration system.
